# 📊 N100 Financial Intelligence Platform

A production-grade Financial Intelligence Platform built for the Nifty 100 companies. The project automates financial data processing, feature engineering, financial health scoring, and interactive business intelligence dashboards for company, sector, and peer analysis.

---

# 🚀 Features

- ETL & Data Validation Pipeline
- Automated Data Cleaning & Preprocessing
- Feature Engineering
- Financial Health Score Engine
- Interactive Streamlit Dashboard
- Company Profile Analysis
- Peer Comparison
- Sector Analysis
- Company Rankings
- KPI Engine
- Financial Reports
- Export to CSV
- SQLite Database Integration
