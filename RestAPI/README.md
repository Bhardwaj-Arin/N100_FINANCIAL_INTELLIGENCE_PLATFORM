## Description

The N100 Financial Intelligence Platform is developed as a Streamlit-based web application.

This project does not implement a separate REST API framework such as Flask, FastAPI, or Django REST Framework. All business logic, financial computations, data processing, and dashboard rendering are executed directly within the Streamlit application.

Therefore, there are no dedicated REST API source files to submit.

The application's functionality is fully contained within the Streamlit source code submitted under the Frontend and Backend sections.
